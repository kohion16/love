THREE DOORS WEBSITE

Files:
- index.html: entrance with three clickable doors
- past.html: Past page and your message
- present.html: Present page and your message
- future.html: Future page and your bullet list
- style.css: shared black background, door styling, and page styling

Preview:
Keep all files in the same folder, then open index.html in Safari.
Click each door to open its page.

Hosting:
Upload all five HTML/CSS files to the root of a GitHub repository
and enable GitHub Pages in Settings > Pages.

Note:
The website is public when hosted on GitHub Pages. Avoid putting
passwords or information you want to keep private in the source.
